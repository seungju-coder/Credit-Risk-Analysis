# Credit Risk Analysis

## 1. 프로젝트 소개
대출 신청자 데이터를 활용하여 고객의 대출 위험도와
개인 특성 및 대출 조건 간의 관계를 분석한 프로젝트입니다.

## 2. 분석 목적
- 어떤 고객군에서 대출 위험률이 높게 나타나는가?
- 소득과 대출 부담률은 위험률과 어떤 관계가 있는가?
- 대출 목적과 주택 소유 형태에 따라 위험률에 차이가 있는가?

## 3. 사용 기술
- Python
- Pandas
- Matplotlib
- Seaborn

## 4. 데이터
- Dataset: Kaggle Credit Risk Dataset
- 분석 대상: 대출 신청자 데이터
- 주요 변수: 소득, 나이, 주택 소유 형태,
  대출 목적, 대출 부담률, 대출 등급 등

## 5. 주요 분석 결과
- 저소득 구간에서 상대적으로 높은 위험률이 나타남
- 대출 부담률이 높을수록 위험률이 증가하는 경향이 나타남
- 대출 등급에 따라 위험률에 차이가 나타남

## 6. 한계점
- 관측 데이터 기반의 분석이므로 인과관계를 확정할 수 없음
- 특정 데이터셋의 특성이 결과에 영향을 줄 수 있음

## 7. 개선 방향
- 머신러닝을 활용한 대출 위험 예측
- 변수 간 상관관계 및 통계적 검정
- 다양한 모델의 성능 비교

## 8. 분석 결과 시각화

### 8-1. 전체 대출 상태 분포

![전체 대출 상태 분포](loan_status_distribution.png)

정상 고객과 위험 고객의 전체 분포를 확인했습니다.

### 8-2. 소득 구간별 위험률

![소득 구간별 위험률](income_risk_rate.png)

소득 구간별 위험률을 비교한 결과, 저소득 구간의 위험률이 가장 높고 고소득 구간의 위험률이 가장 낮게 나타났습니다.

### 8-3. 대출 부담률별 위험률

![대출 부담률별 위험률](loan_burden_risk_rate.png)

대출 부담률이 높은 구간에서 위험률이 크게 증가했습니다. 특히 가장 높은 부담률 구간의 위험률은 46.6%로 나타났습니다.

### 8-4. 대출 목적별 위험률

![대출 목적별 위험률](loan_intent_risk_rate.png)

대출 목적별로 위험률에 차이가 나타났으며, 부채 통합 목적의 위험률이 가장 높았습니다.

### 8-5. 주택 소유 형태별 위험률

![주택 소유 형태별 위험률](home_ownership_risk_rate.png)

임대 고객군의 위험률이 상대적으로 높고, 자가 보유 고객군의 위험률은 낮게 나타났습니다.

### 8-6. 대출 등급별 위험률

![대출 등급별 위험률](loan_grade_risk_rate.png)

대출 등급별 위험률을 비교한 결과, A등급에서 G등급으로 갈수록 위험률이 크게 높아지는 경향이 나타났습니다.
