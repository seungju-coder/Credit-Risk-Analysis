# Credit Risk Analysis

## 1. 프로젝트 소개
대출 신청자 데이터를 활용하여 고객의 대출 위험도와
개인 특성 및 대출 조건 간의 관계를 분석한 프로젝트입니다.

## 2. 분석 목적
- 어떤 고객군에서 대출 위험률이 높게 나타나는가?
- 소득과 대출 부담률은 위험률과 어떤 관계가 있는가?
- 대출 목적과 주택 소유 형태에 따라 위험률에 차이가 있는가?

## 3. 사용 기술
- Python
- Pandas
- Matplotlib
- Seaborn

## 4. 데이터
- Dataset: Kaggle Credit Risk Dataset
- 분석 대상: 대출 신청자 데이터
- 주요 변수: 소득, 나이, 주택 소유 형태,
  대출 목적, 대출 부담률, 대출 등급 등

## 5. 주요 분석 결과

### 5.1 소득 구간별 위험률

| 소득 구간 | 위험률 |
| Low | 39.70% |
| Mid-Low | 21.32% |
| Mid-High | 17.07% |
| High | 9.11% |

- 저소득 구간의 위험률은 39.70%로 가장 높게 나타남
- 고소득 구간의 위험률은 9.11%로 가장 낮게 나타남
- 두 구간의 위험률 차이는 약 30.58%p임
- 소득이 낮은 구간에서 상대적으로 높은 위험률이 나타나는 경향을 확인함

### 6-6. 대출 등급별 위험률

## 7. 결론

본 프로젝트에서는 대출 신청자 데이터를 활용하여
개인 특성과 대출 조건에 따른 위험률 차이를 분석하였다.

분석 결과, 소득 구간과 대출 부담률, 대출 등급 등에 따라
위험률에 차이가 나타나는 것을 확인하였다.

특히 소득 구간별 분석에서는
Low 구간의 위험률이 39.70%로 가장 높았으며,
High 구간은 9.11%로 가장 낮게 나타났다.

이를 통해 대출 위험도 분석에서
고객의 소득 수준과 대출 조건을 함께 고려할 필요가 있음을 확인하였다.

다만 본 분석은 관측 데이터에 기반한 탐색적 분석이므로,
변수 간 관계가 인과관계를 의미하는 것은 아니다.

## 8. 한계점 및 개선 방향

- 관측 데이터 기반의 분석이므로 인과관계를 확정할 수 없음
- 특정 데이터셋의 특성이 결과에 영향을 줄 수 있음
- 향후 머신러닝을 활용한 대출 위험 예측 모델 구축 가능
- 변수 간 통계적 검정 및 모델 성능 비교를 통해 분석 확장 가능
